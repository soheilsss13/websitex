# x — از شب تا سپیده

وب‌سایت تک‌صفحه‌ای فارسی و راست‌چین برای یک برند سرمایه‌گذاری جسورانه با نام موقت **x**. پیاده‌سازی عمداً بدون فریم‌ورک و وابستگی CDN انجام شده است تا سبک، قابل‌ویرایش و مناسب انتشار روی GitHub Pages باشد.

## اجرای محلی

هیچ نصب یا build step لازم نیست. فایل `index.html` را باز کنید یا از یک سرور استاتیک استفاده کنید:

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173` را باز کنید.

## انتشار روی GitHub Pages

صفحه در حال حاضر از ریشه‌ی شاخه‌ی کاری همین نسخه (`arena/4635e2ee-websitex`) منتشر می‌شود؛ بنابراین نیازی به merge نیست. تنظیم مخزن روی **Deploy from a branch → شاخه‌ی `arena/4635e2ee-websitex` → فولدر `/ (root)`** قرار گرفته است و pushهای بعدی به همین شاخه، Pages را به‌روزرسانی می‌کنند.

آدرس سایت: <https://soheilsss13.github.io/websitex/>

برای دامنه‌ی اختصاصی، آن را در **Settings → Pages → Custom domain** وارد کنید و DNS را طبق راهنمای GitHub تنظیم کنید. مسیرهای سایت نسبی‌اند و با آدرس پروژه‌ای GitHub Pages سازگارند.

## بخش‌های پیاده‌سازی‌شده

- طراحی RTL فارسی، لوگوی اختصاصی SVG و فونت‌های self-hosted (Vazirmatn، Inter و IBM Plex Mono)
- هیروی شب با تصویر تولیدشده‌ی کریستال، حرکت Canvas، ساعت سپیده، نوار پیشرفت، منوی تمام‌صفحه و نشانگر موس دسکتاپ
- مانیفست پرشونده با تصویر کریستال بازشده، تصویر تولیدشده برای هر ۸ حوزه، شبکه‌ی مزیت‌ها، طلوع، ۸ مزیت و مسیر ۵مرحله‌ای
- پورتفولیوی نمونه با فیلتر، معیارها و Red Flagها، ماشین‌حساب Runway زنده، بخش درباره، یادداشت‌ها و شبکه‌ی همکاری
- فرم چندمرحله‌ای با اعتبارسنجی و ذخیره‌ی پیش‌نویس در مرورگر
- طراحی واکنش‌گرا، ناوبری کیبورد و پشتیبانی از `prefers-reduced-motion`

## پیش از انتشار رسمی

اطلاعاتی که از شرکت دریافت نشده عمداً به‌صورت **نمونه/نیازمند تکمیل** مشخص شده‌اند. پیش از معرفی سایت به‌عنوان وب‌سایت رسمی:

- نام، لوگو، ایمیل، تلفن، نشانی، آمار و وضعیت واقعی پذیرش را جایگزین کنید.
- نمونه‌کارها و یادداشت‌های نمایشی را با اطلاعات واقعی و مجوزهای استفاده از نام/تصویر عوض کنید.
- بازه‌ی مبلغ، مرحله‌های موردپذیرش، اولویت‌ها و معیارهای قطعی را تأیید و تکمیل کنید.
- لینک‌های شبکه‌های اجتماعی، حریم خصوصی، قوانین و مجوزهای واقعی را اضافه کنید.
- در صورت نیاز به درخواست واقعی، OTP، بارگذاری Pitch Deck، پروفایل متقاضی یا ثبت سمت سرور، یک API امن و سرویس ذخیره‌سازی جداگانه متصل کنید.

**نکته‌ی فرم:** GitHub Pages فقط میزبانی استاتیک است. فرم فعلی صرفاً نمونه‌ی رابط کاربری است؛ داده‌ها فقط در مرورگر کاربر ذخیره می‌شوند و به جایی ارسال نمی‌شوند. این رفتار در خود فرم نیز شفاف اعلام شده است.

## فایل‌ها

- `index.html` — محتوای صفحه و فرم
- `404.html` — صفحه‌ی مسیر ناموجود برای GitHub Pages
- `styles.css` — سیستم طراحی و واکنش‌گرایی
- `script.js` — تعاملات و افکت‌ها
- `assets/logo.svg` و `assets/favicon.svg` — هویت بصری
- `assets/images/` — تصویرهای تولیدشده‌ی هیرو، کریستال بازشده، شبکه، طلوع، ۸ حوزه، کارت پورتفولیو، فرم درخواست، OG، ۴۰۴ و بافت گره‌چینی (تصویرهای مفهومی، نه عکس پروژه‌ی واقعی)
- `assets/fonts/` — فونت‌های محلی و مجوزهای آن‌ها
