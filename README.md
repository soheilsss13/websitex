# x — سرمایه‌گذاری جسورانه

وب‌سایت تک‌صفحه‌ای فارسی و راست‌چین برای برند سرمایه‌گذاری با نام موقت **x**. طراحی تازه، روشن و تایپوگرافیک است؛ بدون فریم‌ورک رابط کاربری، کارت‌های تکراری یا وابستگی CDN. برای انیمیشن قهرمان صفحه، یک صحنه‌ی واقعی WebGL با Three.js به‌صورت محلی bundle شده است.

## پیش‌نمایش محلی

```bash
python3 -m http.server 4173
```

بعد `http://localhost:4173` را باز کنید. برای توسعه‌ی صحنه‌ی سه‌بعدی، پس از نصب وابستگی‌های ساخت اجرا کنید:

```bash
npm install
npm run build:crystal
```

نسخه‌ی قابل‌استفاده‌ی مستقیم در GitHub Pages در `assets/js/crystal-scene.js` قرار دارد؛ انتشار Pages به build step نیاز ندارد.

## صحنه‌ی سه‌بعدی

- موتور: **Three.js 0.186.1 / r186**، با مجوز MIT؛ بررسی نسخه از مخزن رسمی [`mrdoob/three.js`](https://github.com/mrdoob/three.js).
- در جست‌وجوی GitHub، نسخه‌های تازه‌ی [Babylon.js 9.30](https://github.com/BabylonJS/Babylon.js/releases/tag/9.30.0) و [PlayCanvas 2.23.2](https://github.com/playcanvas/engine/releases/tag/v2.23.2) هم بررسی شدند؛ هر دو موتور کامل‌تری هستند. برای یک صحنه‌ی سفارشی در سایت استاتیک، Three.js با bundle درخت‌تکانی‌شده و بدون CDN انتخاب شد. `model-viewer` برای نمایش مدل آماده مناسب است، نه این حرکت چندقطعه‌ای.
- هندسه‌ی کریستال از وجه‌های مستقل سه‌بعدی، هسته‌ی مرکزی و دو مدار ظریف ساخته شده است؛ خودِ مدل در محورهای سه‌بعدی می‌چرخد.
- سه قطعه‌ی شیشه‌ای جداگانه با alpha واقعی در `assets/images/crystal-shard-01.png` تا `03.png` هستند. فایل `assets/images/crystal-sprite-sheet.png` اطلس شفاف همان سه قطعه است و هر خانه جداگانه در صحنه حرکت می‌کند.
- نورهای بازتابی برای متریال شیشه فقط یک بار هنگام راه‌اندازی آماده می‌شوند؛ صحنه بدون سایه‌ی زنده و post-processing رندر می‌شود، وضوح پیکسل در نمایشگرهای متراکم محدود است و انیمیشن هنگام خارج‌شدن از viewport یا مخفی‌شدن زبانه متوقف می‌شود.
- اگر WebGL در دسترس نباشد، سه تصویر شفاف به‌عنوان fallback نمایش داده می‌شوند. کنترل مکث و `prefers-reduced-motion` نیز پشتیبانی می‌شود.
- کد قابل‌ویرایش صحنه: `src/crystal-scene.js`. اسکریپت bundle: `scripts/build-crystal.mjs`. متن مجوز موتور: `assets/js/THREE-LICENSE.txt`.

## انتشار روی GitHub Pages

مخزن از **Deploy from a branch → `arena/4635e2ee-websitex` → `/ (root)**` استفاده می‌کند. این نسخه روی همان شاخه می‌ماند و نیازی به merge به `main` ندارد.

آدرس فعلی: <https://soheilsss13.github.io/websitex/>

پیوندهای داخلی و دارایی‌ها با مسیر پروژه‌ای GitHub Pages سازگارند. برای دامنه‌ی اختصاصی، دامنه را در **Settings → Pages → Custom domain** تنظیم و DNS را طبق راهنمای GitHub پیکربندی کنید.

## فرم و محتوای پیش از انتشار

GitHub Pages میزبانی استاتیک است. فرم صفحه فقط یک پیش‌نویس را در `localStorage` همان مرورگر ذخیره می‌کند و **هیچ داده‌ای ارسال نمی‌کند**. برای دریافت درخواست واقعی باید یک API یا سرویس فرم امن متصل شود.

نام شرکت فعلاً `x` است و حوزه‌های فهرست‌شده صرفاً موضوع‌های پیشنهادی برای شروع گفت‌وگو هستند. پیش از معرفی رسمی، نام و هویت نهایی، حوزه‌های قطعی، ایمیل/راه تماس و سیاست حریم خصوصی را تأیید کنید. هیچ آمار، نمونه‌کار، نشانی یا وضعیت پذیرش ساختگی در صفحه درج نشده است.

## فایل‌های اصلی

- `index.html` — محتوای RTL فارسی و فرم پیش‌نویس
- `styles.css` — طراحی روشن و واکنش‌گرا
- `script.js` — منو، فرم محلی و کنترل حرکت
- `src/crystal-scene.js` — صحنه‌ی Three.js مستقل
- `assets/js/crystal-scene.js` — bundle آماده‌ی مرورگر برای Pages
- `assets/images/crystal-shard-*.png` و `crystal-sprite-sheet.png` — اجزای شیشه‌ای مجزا با پس‌زمینه‌ی شفاف
- `assets/logo.svg` و `assets/favicon.svg` — نشانه‌ی هندسی x
- `404.html` — صفحه‌ی مسیر ناموجود
- `assets/fonts/` — فونت‌های محلی و مجوزهایشان
